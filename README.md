 🌍 Travel Itinerary Planner

A Python-based command-line application that helps users plan trips by creating
7-day itineraries and calculating realistic travel budgets.

This project is designed for beginners and demonstrates how Python can be used
to build real-world applications using logic, data structures, and user input.

---
 ✨ Features

- Interactive command-line interface
- Predefined 7-day itineraries for popular Indian destinations
- Supports Hotel and Hostel stay options
- Food budget options (Street food, Café, Premium)
- Transparent budget calculator with step-by-step explanation
- Shows best time to visit, weather suggestion, and Google Maps link
- Saves trip plan and budget to a JSON file
- Beginner-friendly and easy to extend

---

 🏙️ Supported Destinations

- Manali
- Goa
- Jaipur
- Munnar
- Varanasi

(Users can extend the project by adding more destinations.)

---

 🧮 Budget Calculation Breakdown

The budget is calculated using the following components:

- 🏨 Stay cost = (Hotel / Hostel price per night × Number of days)
- 🍽️ Food cost = (Selected food style per day × Number of days)
- 🎟️ Activity cost = Sum of selected attractions
- 🚕 Local travel cost = Fixed daily estimate

Users can choose to view the full step-by-step calculation.
